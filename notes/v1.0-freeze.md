# BioTerm-Bench v1.0 freeze

BioTerm-Bench v1.0 is the unified 50-task benchmark selected on 2026-08-27.
The previous core-25, hard-8, candidate batches, and generation waves are
development provenance, not public benchmark subdivisions.

The immutable sources of truth are:

- `configs/benchmark_v1.0_manifest.json` — version, task-set digest, container
  digests, selection-artifact hashes, and protocol identity.
- `configs/benchmark_v1.0_tasks.tsv` — public ID to source-directory mapping
  and per-task checksums.
- `configs/benchmark_tasks_50.txt` — Harbor source-task include list.
- `paper/generated/final-benchmark-selection/README.md` — selection method and
  readable composition.

Verify the frozen set with:

```bash
python3 scripts/freeze_benchmark_v1.py --verify
```

Any change to a task directory, task membership, public mapping, selection
receipt, or locally available release image is reported as a freeze violation.
Do not regenerate the v1.0 receipt after a mismatch. Decide whether the change
is a patch-compatible grader correction or requires a later benchmark version.

## Known limitation

The selected set separates weak, middle, and strong deployments, but several
frontier deployments are near ceiling. This is a documented v1.0 limitation,
not grounds for post-freeze task replacement.

## Receipt correction, 2026-11-03

The original receipt could not be verified from a clean checkout. Its task
checksums hashed every file in each task directory, including
`__pycache__/check.cpython-314.pyc` bytecode left behind by local grader runs.
Git ignores those files, so 21 of the 50 checksums depended on files that are
never committed.

Checksums now cover task files only. **No task content changed**: every task
file is byte-identical to the set selected on 2026-08-27, and `frozen_at` and
all other receipt fields are unchanged. This is a correction to how the receipt
is computed, not a new benchmark version.
